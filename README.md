# Number Game

## Description
This project is a Java-based Number Game developed as part of the CodSoft Java Development Internship.
The program generates a random number between 1 and 100. The user has to guess the correct number within a limited number of attempts. The program provides feedback indicating whether the guess is too high or too low.
The game also supports multiple rounds and calculates the user's score.

## Features
* Generates a random number between 1 and 100
* Takes user input using Scanner
* Provides high and low feedback
* Limits the number of attempts
* Supports multiple rounds
* Calculates the user's score
* Handles invalid input
  
## Technologies Used
* Java
* Scanner
* Random
* Loops
* Conditional Statements
  
## How to Run
### Step 1: Compile the program
javac NumberGame.java

### Step 2: Run the program
java NumberGame
