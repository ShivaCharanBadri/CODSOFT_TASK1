# Number Game

## Description
The Number Game is a console-based Java application developed as part of the CodSoft Java Development Internship.
In this game, the computer generates a random number between 1 and 100. The user must guess the correct number within a limited number of attempts.
After every guess, the program provides feedback indicating whether the guessed number is too high, too low, or correct. The game supports multiple rounds and calculates a score based on the number of attempts used.
This project demonstrates the use of fundamental Java programming concepts such as user input, random number generation, conditional statements, loops, and input validation.

## Features
* Generates a random number between 1 and 100
* Accepts user guesses through the console
* Provides feedback when the guess is too high
* Provides feedback when the guess is too low
* Detects the correct guess
* Limits the number of attempts
* Displays remaining attempts
* Supports multiple rounds
* Calculates the score for each round
* Displays the total score
* Handles invalid input
* Displays the total number of rounds won

## How to Run

### Step 1: Clone or Download the Repository
Download or clone this repository to your computer.

### Step 2: Open the Project Folder
Open the folder containing:
NumberGame.java

### Step 3: Compile the Program
Open the terminal inside the project folder and run:
javac NumberGame.java

### Step 4: Run the Program
java NumberGame

## Sample Functionality
The user enters a number between 1 and 100.
The program compares the entered number with the randomly generated number and displays one of the following messages:
* Too high
* Too low
* Correct guess
The user has a limited number of attempts to guess the correct number.
After completing a round, the user can choose to play again.
